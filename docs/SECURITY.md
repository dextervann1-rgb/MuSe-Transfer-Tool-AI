# Security Guidance

## Do not publish secrets

Never commit API keys, tokens, `.env` files, live repository lists, private endpoints, operational manifests, or personal collaboration data to this public repository. Generic templates are acceptable only when their values are blank or demonstrably non-sensitive.

## Reporting a concern

Do not open a public issue with credentials, private URLs, reproducible exploit details, personal data, or confidential artifacts. Contact the repository owner through a private channel and provide only the minimum information needed to verify the concern.

## Public-shell limitation

This repository is not a live service and does not contain the private MuSe core. Reported concerns should focus on public documentation, generic interface contracts, or any material accidentally released into this public shell.
